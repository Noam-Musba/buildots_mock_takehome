# SiteFlow Issues

A small React + TypeScript issue-tracking dashboard used by site teams to review construction observations.

## Getting started

```bash
npm install
npm run dev
```

Useful commands:

```bash
npm run test
npm run build
```

## Notes

- The API in `src/api/issuesApi.ts` is intentionally mocked in-memory. Treat it as if it were a real remote API.
- Network latency and occasional failures are simulated.
- Please keep the existing stack unless the assignment clearly requires otherwise.
